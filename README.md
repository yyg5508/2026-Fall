요즘 뉴스에서 “AI가 인간을 대체한다”라는 문구들과 함께 자극적인 이야기들을 자주 다뤄 AI 기술이 계속 발전하면서 취업한 후에 내 자리가 없어질까 봐 걱정부터 앞섰다. 그런데 AI가 일을 통째로 뺏어가는 게 아니라, 반복적인 업무의 30~40% 정도를 대신해 준다는 말이 와닿았다. 비개발자인 평범한 마케터도 AI를 써서 업무 스크립트를 짜고 문제를 해결한다는 사례를 보며, 앞으로는 스스로 문제를 찾고 도구를 활용해 해결하는 행동력이 진짜 중요해질 것 같다고 느꼈다.
또, AI에 민감한 데이터를 제공할 때 생기는 프라이버시 문제에 대해서도 명확한 답을 얻었다. 항상 AI에 많은 개인적인 것들을 물어보면서 걱정을 했었는데, 보안과 신뢰성이 핵심 자산인 대형 클라우드 기업의 AI는 상대적으로 믿을 만하다는 말에 안심이 되었다. 
그러나, 영상의 주장에 100% 동의하는 건 아니다. 소프트웨어 엔지니어 채용이 늘었다는 건 지금이 AI 붐이라서 생기는 일시적인 현상일 수 있다고 생각한다. 사무직처럼 반복 업무가 많은 곳에서는 이미 일자리가 줄어들고 있는데, 너무 실리콘밸리 전문가 입장에서만 긍정적으로 본 게 아닌가 하는 아쉬움도 들었다.
